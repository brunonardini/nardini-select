# Design docs

Approved EGM design docs live here, one file per feature (`<feature>.md`).

1. Explore and draft: `/egm:egm-brainstorm`, then `/egm:egm-draft`. Drafts stay in `.dev/docs/` (gitignored).
2. Review: `/egm:egm-review`, then `/egm:egm-resolve`.
3. Commit the approved doc here. Code starts only after that.

Small changes (copy tweaks, one-off fixes) don't need a doc. Run `/egm:egm-drift-report` from time to time to catch drift between these docs and the code.

The current home page predates EGM; its approved spec is [design/home-content-v3.md](../../design/home-content-v3.md).
