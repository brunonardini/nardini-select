# Design docs

Approved design docs live here, one file per feature (`<feature>.md`).

1. Draft with the `design-doc` skill. Drafts and review notes stay in `.dev/docs/<feature>/` (gitignored).
2. One fresh-context reviewer checks the draft; the findings are resolved with the author.
3. Commit the approved doc here. Code starts only after that.

Small changes (copy tweaks, one-off fixes) don't need a doc. Ask the `design-doc` skill for a drift check from time to time to catch differences between these docs and the code.

The current home page predates these docs; its approved spec is [design/home-content-v3.md](../../design/home-content-v3.md).
