# Security policy

Please don't report security vulnerabilities through public GitHub issues, pull requests, or discussions.

Report them privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Only the maintainer can see the report. Include what you found, the steps to reproduce it, and the impact you expect.

Only the latest version, the one deployed at [nardiniselect.com.br](https://nardiniselect.com.br), receives fixes.
